# cobaia-producao

Kit de produção dos vídeos do @cobaia.dev ("30 dias, 30 experimentos com Claude"). A regra principal é o [Dossiê Cobaia 2.0](DOSSIE.md); o acabamento do motion segue o Dia 10 v3.

**Se você é um Claude:** comece pelo [`CLAUDE.md`](CLAUDE.md).

**Para o Luis, abrir numa conta nova do Claude:**
1. Conecte o GitHub na conta e dê acesso a este repositório.
2. Instale a skill: veja [`skill/COMO-INSTALAR.md`](skill/COMO-INSTALAR.md).
3. Num projeto ou sessão com este repositório, peça: "Leia o CLAUDE.md e produza o Dia NN". A outra conta vai dar `git pull` antes e registrar no `CHANGELOG.md` tudo o que melhorar.

Histórico de mudanças: [`CHANGELOG.md`](CHANGELOG.md).
